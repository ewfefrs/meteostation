# Метеостанция на ESP32

Домашняя цифровая метеостанция. ESP32 с датчиком BME280 измеряет температуру, влажность и давление,
показывает их на OLED-экране, ведёт журнал и отдаёт данные по Wi-Fi приложению для Android.
Скрипт на Python сравнивает показания станции с данными официальной метеостанции.

```
firmware/meteostation_esp32/   прошивка ESP32 (Arduino IDE)
android/MeteoStation/          приложение для Android (Kotlin, Jetpack Compose)
analysis/compare.py            сравнение с официальной метеостанцией (Python)
```

## Детали

- ESP32 DevKit V1 (ESP32-WROOM-32)
- датчик BME280 (именно BME, с влажностью; BMP280 не подойдёт)
- OLED-дисплей 0.96" I2C 128×64 (SSD1306)
- макетная плата, провода Dupont, USB-кабель с передачей данных, блок питания 5 В

Итого около 1500–2000 ₽. Пайка не нужна.

## Подключение

BME280 и OLED подключаются параллельно по I2C:

| Вывод модуля | ESP32  |
|--------------|--------|
| VCC / VIN    | 3V3    |
| GND          | GND    |
| SDA          | GPIO21 |
| SCL          | GPIO22 |

Датчик лучше вынести на проводах на 20–30 см от платы, потому что ESP32 греется. На улице его нужно
ставить в тени и в месте, защищённом от дождя и снега.

## Запуск

1. **Прошивка.** В Arduino IDE установить платы **esp32 by Espressif Systems** 3.x и библиотеки
   **Adafruit BME280**, **Adafruit SSD1306**, **Adafruit GFX**. Плата: «ESP32 Dev Module», Partition Scheme:
   «Default 4MB with spiffs». Открыть `meteostation_esp32.ino` и загрузить.
2. **Приложение.** В Android Studio открыть папку `android/MeteoStation` и нажать Run (или Build → Build APK).
3. **Первое подключение.** Станция создаёт точку доступа **MeteoStation** (пароль `meteo2026`).
   Подключить к ней телефон, затем в приложении открыть «Настройки», указать адрес `192.168.4.1` и ввести
   данные домашней Wi-Fi-сети. Станция перезагрузится и подключится к ней.
4. **Высота.** В настройках указать высоту датчика над уровнем моря: высота земли по карте + (этаж − 1) × 3 м + 1 м.
   Она нужна, чтобы привести давление к уровню моря.

Если на экране станции горит `NO TIME`, у неё нет точного времени и журнал не пишется. Время берётся
из интернета или из подключённого телефона.

## Сравнение с официальной метеостанцией

1. В приложении: «Графики» → «Экспорт журнала в CSV».
2. На rp5.ru скачать архив погоды своего города за тот же период: формат CSV, кодировка UTF-8.
3. Запустить:
   ```
   pip install matplotlib
   python analysis/compare.py станция.csv rp5.csv
   ```
   Результат (таблица отклонений и графики) появится в `analysis/results/`.

## HTTP API станции

| Запрос | Назначение |
|---|---|
| `GET /` | страница с текущими значениями |
| `GET /api/now` | текущие значения, JSON |
| `GET /api/history?since=EPOCH` | записи журнала новее EPOCH, CSV `ts;t;h;p` |
| `GET /api/log.csv` | весь журнал |
| `GET/POST /api/config?alt=60&interval=10` | высота датчика (м), интервал записи (мин) |
| `POST /api/time?epoch=...` | установить время |
| `POST /api/wifi?ssid=...&pass=...` | сохранить домашнюю сеть |
| `POST /api/clear` | очистить журнал |
